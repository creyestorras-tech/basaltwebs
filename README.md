# Basalt Webs

Web de Basalt Webs (https://basaltwebs.pages.dev). Astro estàtic, català (`/`) i castellà (`/es/`).

## Abans de publicar

Omple els camps entre claudàtors a `src/config/site.ts`: `[EL TEU NOM]`, `[MÒBIL]` (format `34612345678`),
`[CORREU]`, `[TITULAR]`, `[NIF]` i els dos `[PREU]`. Tots els textos són a `src/i18n/content.ts`.

## Cloudflare Pages

- Framework preset: Astro
- Build command: `npm run build`
- Build output directory: `dist`
- Variable d'entorn: `NODE_VERSION=22`

## Desenvolupament

```bash
npm install
npm run dev
```
